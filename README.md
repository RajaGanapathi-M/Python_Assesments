# Python Module Assessment

A collection of Python programming exercises designed to strengthen **Python fundamentals, problem-solving, algorithmic thinking, and code efficiency**.

## 📌 Overview

This repository contains assessment problems organized into topic-based modules. Each module includes:

- Python problem statements in PDF format
- Individual `.py` solution files
- Test cases for selected problems
- Practical exercises ranging from basic programming to algorithmic problems

## 🧩 Modules

### 1. Coding Basics
Covers fundamental Python programming concepts such as:

- Functions
- Arithmetic operations
- Variables and data types
- Mathematical calculations
- String manipulation
- Basic problem solving
- Fibonacci numbers

### 2. Conditional Concepts
Focuses on decision-making and conditional logic:

- `if`, `elif`, and `else`
- Comparisons
- Boolean expressions
- Conditional calculations
- Grade classification
- Input validation
- Problem-specific decision logic

### 3. Loops Concepts
Introduces repetition and iterative problem solving:

- `for` loops
- `while` loops
- Digit processing
- Number manipulation
- String processing
- Prime-number calculations
- Collatz sequence
- Character validation

### 4. Nested Loops Concepts
Covers more advanced iteration techniques:

- Nested `for` loops
- Nested `while` loops
- Pattern and sequence generation
- Student grade processing
- Recursive problem solving
- Digit counting
- Coin sequence generation

### 5. Algorithmic Thinking
Develops logical and algorithmic problem-solving skills:

- String-to-number conversion
- Ordering and comparison
- Graph/network-related problems
- Factor analysis
- Interactive Hangman game
- Breaking complex problems into smaller steps

### 6. Efficiency Python Code
Introduces techniques for writing more efficient solutions:

- Dictionary operations
- Set intersections
- Duplicate detection
- Graph-related problems
- Clique problems
- Index/range processing
- Improving algorithmic efficiency
